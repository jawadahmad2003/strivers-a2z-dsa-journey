# Day 03 – Pattern Problems (1–10)

##  Overview
This folder contains my solutions to **Pattern Problems 1–10** from the Striver A2Z DSA Course, implemented in Python.

The main goal of these problems is to strengthen my understanding of nested loops, iteration, and problem-solving logic.

- Outer loop and inner loop

- Printing patterns using `print()`

- Spaces and stars alignment
- Dry runs and logical thinking
